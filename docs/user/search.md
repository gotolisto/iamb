# Search

The search window lets you find a snippet without remembering its abbreviation. Find it, press
Enter, and Iamb inserts it into the app you were using.

## Open search

Press **Ctrl+Shift+Space** (**⌃⇧Space** on macOS).

You can change this shortcut in [Settings](settings.md#shortcuts). You can also choose **Search
snippets…** from the menu. In the library window, press **Ctrl+K** (**⌘K** on macOS) to open the same
search over the library. Choosing a snippet there selects it in the library instead of typing it.

Search does not work while a fill-in form is open. It works while Iamb is paused.

## Find a snippet

Type part of the abbreviation, label, text or tag. The list narrows as you type.

- Each row shows the label, the abbreviation, the folder and the first line of the snippet.
- A snippet that asks for values shows an **Asks for values** icon.
- A snippet that is off, or that has an error, shows a badge.
- The preview under the list shows the first lines of the selected snippet.

With the search box empty, you see:

- **Fill in “…” again**, when you used a fill-in form in the last 30 minutes. See
  [Fill-in forms](forms.md#your-last-answers).
- The snippets you used most recently on this computer.

The search is not saved. It starts empty each time you open it.

If nothing matches, the window says **No snippet matches “…”** and offers to make a new snippet with
that label.

## Choose a snippet

| Key | What it does |
| --- | --- |
| **Up** and **Down** | Move between results. The list wraps around. |
| **Page Up** and **Page Down** | Jump through the list. |
| **Enter** | Does what the footer says for the selected row: insert it, fill it in and insert it, or open it. |
| **Ctrl+1** to **Ctrl+9** (**⌘1** to **⌘9** on macOS) | Choose that row. |
| **Ctrl+E** (**⌘E** on macOS) | Open the selected snippet in the library to edit it. |
| **Esc** | Close search without inserting anything. |

Pressing the search shortcut again also closes it.

If Iamb cannot insert the snippet, for example because the field is a password field, it shows a
short notice and types nothing. See [Fill-in forms](forms.md#when-iamb-cannot-type).
