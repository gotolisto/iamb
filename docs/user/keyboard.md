# Keyboard

Every task in Iamb can be done from the keyboard. This page lists the shortcuts.

On macOS, use **⌘** (Command) where this page says **Ctrl**, unless a row says otherwise. Shortcuts
are shown on the controls they work with.

## Global

These work in any app.

| Action | Windows | macOS | Changeable |
| --- | --- | --- | --- |
| Search snippets | Ctrl+Shift+Space | ⌃⇧Space | Yes, in [Settings](settings.md#shortcuts) |
| Fill in the last form again | Not set | Not set | Yes, in [Settings](settings.md#shortcuts) |
| Pause or resume | Not set | Not set | Yes, in [Settings](settings.md#shortcuts) |

The last two have no shortcut until you set one. Without one, fill in the last form again from
[search](search.md) or the menu, and pause from the menu's **Pause Iamb** or the switch in
[Settings](settings.md#general).

## Library window

| Action | Windows | macOS |
| --- | --- | --- |
| New snippet | Ctrl+N | ⌘N |
| New folder | Ctrl+Shift+N | ⌘⇧N |
| Save the open snippet | Ctrl+S | ⌘S |
| Filter the list | Ctrl+F | ⌘F |
| Search over the library | Ctrl+K | ⌘K |
| Focus the sidebar, the list, the editor | Ctrl+1, Ctrl+2, Ctrl+3 | ⌘1, ⌘2, ⌘3 |
| Move between panes | F6 (Shift+F6 backwards) | F6 (Shift+F6 backwards) |
| Settings | Ctrl+, | ⌘, |
| Close the window (Iamb keeps running) | Ctrl+W | ⌘W |
| Zoom in, out, reset | Ctrl++, Ctrl+-, Ctrl+0 | ⌘+, ⌘-, ⌘0 |

## Snippet list

| Action | Keys |
| --- | --- |
| Move up and down | Up, Down (Home and End jump to the ends; Page Up and Page Down jump by a page) |
| Jump to a snippet by its label | Type the first letters |
| Open the selected snippet in the editor | Enter |
| Turn the selected snippet on or off | Space |
| Duplicate | Ctrl+D (⌘D) |
| Delete (with Undo for 10 seconds) | Delete (on macOS, ⌘⌫ or Delete) |
| Select every snippet | Ctrl+A (⌘A) |
| Extend the selection | Shift with an arrow key |
| Open the menu for the selected snippet | Shift+F10, or the context menu key |

In the folder list, **F2** renames the folder (on macOS, Enter does too), **Delete** deletes it, and
the context menu key or Shift+F10 opens its menu. On a tag, **F2** opens its menu.

## Snippet editor

| Action | Windows | macOS |
| --- | --- | --- |
| Save | Ctrl+S | ⌘S |
| Open **Options** | Ctrl+Shift+O | ⌘⇧O |
| Show or hide the preview | Ctrl+Shift+P | ⌘⇧P |
| Bold, italic, link (formatted snippets) | Ctrl+B, Ctrl+I, Ctrl+K | ⌘B, ⌘I, ⌘K |
| Insert something | Type `{`, then type to filter | Type `{`, then type to filter |
| Open a chip's card | Enter or Space on the chip | Enter or Space on the chip |
| Move over a chip, select it, delete it | Left, Right, Shift+Left, Shift+Right, Backspace | Same keys |
| Leave a chip's card | Esc | Esc |

Tab moves to the next control. It does not type a tab character, so you can always leave the
editor from the keyboard.

## Fill-in form

| Action | Keys |
| --- | --- |
| Next field, previous field | Tab, Shift+Tab |
| Insert | Enter (in a several-line field, Ctrl+Enter or ⌘Enter) |
| Cancel | Esc |
| Choose an option in a choice field | Up, Down, or type its first letters |
| Check or uncheck a toggle | Space |
| Start with empty fields (only when your last answers are shown) | Ctrl+Backspace (⌘Backspace) |

## Search window

| Action | Keys |
| --- | --- |
| Move through results | Up, Down (the list wraps around) |
| Jump through results | Page Up, Page Down |
| Insert the snippet, fill it in, or open it | Enter |
| Insert a result directly | Ctrl+1 to Ctrl+9 (⌘1 to ⌘9) |
| Edit the selected snippet in the library | Ctrl+E (⌘E) |
| Close | Esc, or the search shortcut again |

## Settings

| Action | Keys |
| --- | --- |
| Move between sections | Tab, then Enter to open a section |
| Change the search shortcut | Select the box and press the new keys. Esc leaves it as it was. Backspace clears it. |

## Keys that are not shortcuts

Iamb's own windows use fixed shortcuts, except the search shortcut. In text fields, a single letter or
symbol is always typed as text. In the snippet and folder lists, typing a letter jumps to the next item
that starts with it.
