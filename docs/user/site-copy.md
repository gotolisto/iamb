# Site copy

Draft copy for the Iamb website. Every claim here is covered by the user pages in this folder.

## Homepage hero

**Type a short abbreviation. Get the whole text.**

Iamb is a free, open-source text expander for macOS and Windows. Type `;em` and a space in most apps,
and it becomes your email address.

Button: **Download Iamb** (links to the releases page; the link is a placeholder until installers
are published).

## Feature blurbs

**Save what you type again and again.**
Keep replies, sign-offs, addresses and order numbers as snippets. Each one has a short abbreviation
you type in any app.

**Fill in the blanks.**
A snippet can ask for a name, a choice or a yes-or-no before it inserts, so one snippet works for
many letters.

**Dates, times and formatted text.**
Insert today's date in the format you choose, or a date 14 days from now. Paste bold text, links and
images from a single snippet.

**Find it without remembering it.**
Press one shortcut from any app and search your snippets by label, text or tag. Press Enter to insert.

**Private by design.**
What you type is held in memory for a moment and never saved or sent. Iamb stays out of password
fields it can recognise and out of the apps you exclude.

## FAQ

**Is Iamb free?**
Yes. It is open source under the AGPL-3.0-or-later licence.

**Which computers does it run on?**
The desktop app runs on macOS and Windows. The command-line tool also runs on Linux.

**Does Iamb send what I type anywhere?**
No. What you type stays in memory on your computer and is never saved or sent. The background part
of Iamb that reads your keys has no network code. This version makes no network connections.

**Why doesn't Enter expand a snippet?**
Enter and Tab often send a message or move to the next field before Iamb can type. Finish the
abbreviation with a space or a punctuation mark instead. You can turn Enter on in Settings, with a
warning.

**Does it work in password fields?**
No. Iamb does not expand snippets in password fields it can recognise, and it does not keep what you
type there. A few apps do not say that a field is a password field. Add those to the list of apps
where Iamb stays out.

**Does it work in every app?**
Most text fields work. A few apps need a setting, such as a different way to send the text. See the
troubleshooting guide.

**Do I need an account?**
Not in this version.

**Can I sync between computers?**
Sync is planned, not available yet. For now, copy your library with import and export in the
command-line tool.

**Can I import and export my snippets?**
Yes, with the command-line tool, in JSON or CSV. The desktop app does not have import or export yet.

**Is it ready to use?**
Not yet. Iamb is pre-alpha, and installers are being built now.
