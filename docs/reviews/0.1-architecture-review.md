# Review of the architecture specification (task 0.1)

An independent reviewer, with no access to the author's reasoning, checked the first draft of
`docs/architecture.md`, the decision records and the template specification against a checklist:
every Phase 1 to 4 task maps to a component; nothing is left to be decided; the documents agree
with each other; the design works on Windows and macOS; the privacy rules hold.

Result: 25 findings (7 high, 15 medium, 3 low). All are resolved in the revised documents. The
revision has not yet been reviewed a second time.

| # | Severity | Finding | Resolution |
| --- | --- | --- | --- |
| 1 | High | Keys typed during injection corrupt the expansion | Injector thread, start and end markers, compensation or abandon: §4.6, ADR-0019 |
| 2 | High | A background service cannot restore focus on either OS; the palette had no focus step | The UI host hands focus back using a focus token; non-activating panels on macOS: §4.5, ADR-0013 |
| 3 | High | Settings and hotkeys had no path to the engine or the OS | Settings in the snapshot; `Hotkeys` and `LoginItem` traits; `PaletteRequested`: §3.1, §5, §6.2 |
| 4 | High | Pull by revision misses newly shared folders and never revokes | Per-user change feed with visibility entries, full fetch, purge, recorded conflicts: §9, ADR-0016 |
| 5 | High | Shared snippets are an attack surface; rule 8 overclaimed | Review before use, restricted Markdown, profile-scoped attachments: §8 rule 10, ADR-0022 |
| 6 | High | Windows pipes can be squatted or reached remotely | Exclusive creation, remote clients rejected, peers verified both ways: §6.1, ADR-0006 |
| 7 | High | "Remember last form values" had no home and no privacy rule | Worker memory only, 30 minutes, never logged; `ReopenLastForm`: §4.5, §8 rule 2 |
| 8 | Medium | The service would expand inside Iamb's own windows | `own_window` suspension; declared onboarding test field: §4.5 |
| 9 | Medium | Role and visibility model had holes | Group-owned folders, permission table, tag visibility, shared sub-folders as roots: §7, ADR-0014 |
| 10 | Medium | Sign-in had no process to talk to and no method | Sync agent runs from login; browser sign-in with PKCE; in-app invitations: §6.4, ADR-0020 |
| 11 | Medium | Command-line access to the store was racy | `run/store.lock`; try endpoint, then lock, else stop: §6.3, ADR-0007 |
| 12 | Medium | Every write rebuilt the snapshot and cleared the buffer; no usage signal | Snapshot only on content or settings changes; buffer kept; `Expanded` action: §3.1, §4.1, §4.2 |
| 13 | Medium | Lazy attachments contradict offline use; no owner for the files | Eager download by the sync agent; service resolves references at paste time: §9 |
| 14 | Medium | Effective library, ties and case handling were inconsistent | Matchable and reference sets; case-folded uniqueness; precedence; shadowing; verbatim ranges: §4.4 |
| 15 | Medium | Chord-as-boundary breaks AltGr and Option; translation side effects; input methods; units | Text-yielding keys are characters; stateless translation; `Composing`; units defined: §4.1, §4.2 |
| 16 | Medium | Secure-field detection races typing; diagnostics contradicted the rules | Focus thread with timeout; fail closed; diagnostics name no snippet while suspended: §4.1, §8 |
| 17 | Medium | Form semantics open; 150 ms target failed with the tray off | Clock and clipboard captured at match; one form at a time; UI host always resident: §4.5, §10 |
| 18 | Medium | The supervisor could not detect a hung worker or a removed hook | Heartbeat and hook self-test: §3.2, ADR-0011 |
| 19 | Medium | macOS permissions were checked in the wrong process | Checked in the worker and reported over IPC; signed helper app: §3.2, ADR-0021 |
| 20 | Medium | WebAssembly preview was unplanned | Dropped; the service parses and previews: §6.2, ADR-0017 |
| 21 | Medium | A crate deny list alone cannot prove "no network" | Four checks: §2, ADR-0008 |
| 22 | Medium | Palette search would queue behind writes and was not fuzzy | In-memory search over the snapshot on reader threads: §3.1, §10 |
| 23 | Low | Clipboard history, swap and OS crash dumps | Transient clipboard marks, locked buffer, stated limit: §8 rules 1, 8, 9 |
| 24 | Low | Mobile blocked: sync was only a binary; single-writer rule had no mobile form | `iamb-sync` is a library with a thin binary; same lock rule on mobile: §2, §6.3 |
| 25 | Low | Naming and consistency defects | Trait list, event names, overflow event, `DryRun`, prefix, file paths for bulk data, entitlements, ADR-0020 and ADR-0023 |
