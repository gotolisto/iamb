# ADR-0006: Local IPC: length-prefixed JSON over a user-only socket or named pipe

Status: proposed (awaiting owner approval)

**Context.** The UI host, the command-line tool and the sync agent all need the service. Messages are small and infrequent (the key path does not cross a process).

**Decision.** A Unix domain socket (macOS, Linux) or named pipe (Windows), restricted to the current user and verified on connect. Frames are a 4-byte little-endian length plus a JSON document (at most 8 MB). Requests carry an id; the service also pushes events. The first message is a versioned `Hello` that states the client role, and each role may call only its own message groups.

**Consequences.** Messages are readable in logs and tests, and the contract can be checked with golden files. JSON costs microseconds at this volume. A sync agent bug cannot read diagnostics or pause the engine.

**Rejected.** A binary format (no measurable gain, harder to debug). Local HTTP or WebSocket on a TCP port (reachable by other users and by web pages; needs a network stack in the service). A general RPC framework (large dependency in the process that sees keystrokes).
